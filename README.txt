TaskTracker — локальний Kanban-вебдодаток

ЗАПУСК
1. Відкрийте TaskTracker.html у сучасному браузері (Chrome, Edge, Firefox або Safari).
2. Натисніть «Нове завдання», заповніть форму й натисніть «Зберегти».
3. Перетягніть картку до іншої колонки або змініть статус через «Редагувати».

МОЖЛИВОСТІ
- Створення, редагування та видалення завдань із підтвердженням.
- Колонки: «До виконання», «У роботі», «Готово».
- Назва, опис, пріоритет та термін виконання.
- Пошук і фільтр за пріоритетом, позначення прострочених завдань.
- Збереження у localStorage, адаптивний інтерфейс, світла й темна тема.
- Керування клавіатурою: Tab для переходу між елементами; Esc закриває редактор.
- На телефоні змінюйте статус через редактор — перетягування залежить від браузера.

ТЕХНОЛОГІЇ
HTML5, CSS3, JavaScript без бібліотек і зовнішніх залежностей.
Увесь вихідний код міститься у TaskTracker.html.

ОБМЕЖЕННЯ
Це однокористувацька локальна версія, без сервера, акаунтів і командної синхронізації.
Дані належать конкретному браузеру та розташуванню файлу. Поведінка localStorage
для file:// може відрізнятися між браузерами. Очищення даних браузера або приватний
режим можуть видалити завдання. Не використовуйте це як єдине сховище важливих даних.
За потреби стабільного вебпоходження можна запустити локальний HTTP-сервер:
  python -m http.server 8000
у папці з файлом і відкрити http://localhost:8000/TaskTracker.html.
